## 📜 구현 기능 목록

### 자동차 이름 추출 및 생성
- `,`를 구분하여 자동차 이름을 추출
- 추출된 이름을 이용하여 자동차 생성

### 자동차 이동
- 자동차는 정해진 라운드만큼 이동
- 자동차 별로 0에서 9사이의 무작위 값 부여
- 부여받은 값이 `4` 이상인 자동차는 전진
- 부여받은 값이 `4` 미만인 자동차는 멈춤

### 우승자 선별
- 자동차들의 진행 거리 중 가장 긴 거리를 찾기
- 위에서 찾은 거리와 자동차들을 비교하여 우승자 선별

### 입/출력
#### 입력
- 경주할 자동차 이름 입력
- 몇 라운드를 진행할 것인지 입력

#### 출력
- 라운드별 실행 결과 출력
- 단독/공동 우승자 출력
  - 공동 우승자일 경우 `,`을 이용하여 구분

### ⚠️ 예외 처리
잘못된 값을 입력할 경우 `IllegalArgumentException`를 발생시킨다.
- 자동차 이름이 빈 문자열, 공백, null 일 경우
- 자동차 이름이 5글자를 초과할 경우
- 자동차 이름이 중복되는 경우
- 자동차가 1대 이하인 경우
- 입력 받은 라운드 수가 빈 문자열, 공백, null 일 경우
- 입력 받은 라운드 수가 정수가 아닌 경우 (ex: 3.8, abc)
- 입력 받은 라운드 수가 1미만인 경우

### 2) 기능 요구 사항

- [x] 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
- [x] 각 자동차에 이름을 부여할 수 있다. 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
- [x] 자동차 이름은 쉼표(,)를 기준으로 구분하며 이름은 5자 이하만 가능하다.
- [x] 사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야 한다.
- [x] 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.
- [x] 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다. 우승자는 한 명 이상일 수 있다.
- [x] 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.
- [x] 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료되어야 한다.

### 3) 입출력 요구 사항
- [x] 경주할 자동차 이름(이름은 쉼표(,) 기준으로 구분)을 입력 받는다.
- [x] 시도할 횟수를 입력 받는다.
- [x] 차수별 실행 결과를 출력한다.
- [x] 우승자 안내 문구를 출력한다.(단독/공동)
